 # 🎙️Voice_Powered - Voice Controlled To-Do App
    A voice-enabled To-Do app developed using React, Tailwind CSS, and Vite.
    Simply speak your tasks and manage them effortlessly!

 ## ✨Features
    - Add tasks using voice with the Web Speech API
    - ⌨️ Enter tasks manually via text input
    - 📋 View tasks in an organized list
    - ✅ Mark tasks as completed
    - 🗑 Remove tasks easily
    - 🌙 Switch between Dark and Light modes
    - ⬇️ Export tasks as TXT, CSV, or PDF

 ## ⚙️Tech Stack
    - ⚛️ Built with React
    - 🎨 Styled using Tailwind CSS
    - ⚡ Powered by Vite
    - 🌐 Hosted on Netlify
